# PassionCode.ai organization profile

The `.github` repository of the `passioncode-ai` organization: the public organization profile,
rendered from [`profile/README.md`](profile/README.md), and the defaults every repository without
its own inherits — [`CONTRIBUTING.md`](CONTRIBUTING.md), [`SECURITY.md`](SECURITY.md) and the
[pull request template](.github/pull_request_template.md). Brand assets used by GitHub live in
[`assets/`](assets/).

## Quick start for a new teammate

1. **Install:** nothing to install. `git clone https://github.com/passioncode-ai/.github`; GitHub
   renders the profile at https://github.com/passioncode-ai from `main`.
2. **Configure:** no key. Push access to this repository comes with the organization's
   `contributors` team.
3. **MCP:** none; this repository holds documents, not a product, and serves no MCP.
4. **Develop:** edit `profile/README.md`, `CONTRIBUTING.md` or the templates, then run
   `git diff --check` and confirm every link target resolves; after merge, confirm anonymously
   that https://github.com/passioncode-ai shows the change. [AGENTS.md](AGENTS.md) holds the rules.
